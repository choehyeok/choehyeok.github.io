# 타이쿤 콘텐츠 플레이북 (매일 자동 발행용)

## 0. ★★최우선: 짧고 읽기 쉽게 (사용자 피드백: "글이 너무 길고 별로, 이미지는 좋다")
- 분량: 블로그·워드프레스·깃허브 600~1,000자 / 미디엄·Substack 600~900자 / M2 카드뉴스 본문 300~600자(카드가 주인공). 이 범위를 넘기면 줄일 것.
- 이미지가 주인공: 썸네일 + 본문 이미지가 내용의 절반을 전달. 텍스트는 이미지를 보충하는 정도.
- 한 문단 최대 2문장, 한 문장 40자 안팎. 소제목 3~4개까지. 목록은 3~5개 항목, 항목당 한 줄.
- 같은 말 반복 금지("정산이 빠르다"는 글 전체에서 2번까지). 뻔한 서론·요약 반복·감탄·과장("무조건", "최고", "놓치지 마세요" 남발) 금지.
- 구체적 장면 1개(예: "예약 문의 → 링크 전송 → 결제 → 1시간 뒤 입금")로 설명. 추상적 설명 나열 금지.
- 마무리는 CTA 1줄 + 이탤릭 고지 1줄로 끝. "정리하면", "마지막으로" 반복 금지.

매 발행마다 아래 4가지를 조합합니다: [주제] × [형식] × [제목 패턴] × [이미지 스타일].
같은 채널의 최근 글 5개와 주제·형식·스타일이 겹치지 않게, 같은 날 다른 채널과도 겹치지 않게 고릅니다.
도입 훅·CTA 문구도 아래 목록에서 매번 다른 것을 골라 변형해서 씁니다(그대로 복붙 금지).

## 7. 본문 이미지 규칙
- 블로거·깃허브·워드프레스 글: 썸네일 1장 + 본문 중간 이미지 2장(<슬러그>-2, <슬러그>-3). 미디엄: 본문 이미지 1장.
- 본문 이미지는 s15~s18 중 글 내용에 맞는 것(단계 → s15, 비교 → s16, 체크리스트 → s17, 핵심 문장 → s18). 같은 글 안에서 같은 스타일 반복 금지.
- 각 본문 이미지는 바로 앞 소제목 내용을 요약(문구 8~16자). alt 텍스트에 핵심 키워드. 금액은 예시용 둥근 숫자(예: 380,000 / 1,240,000)로 다양하게.

## 8. ★선두기업 스타일 (필수 비중 — 매일 12개 중 M1 최소 5개, M2 최소 2개, 나머지는 F01~F30)
"메일·편지처럼 읽히는 글" 금지: "안녕하세요 사장님", "~드립니다", "오늘은 ~를 알려드릴게요" 식 인사·편지체 도입 금지. 첫 문장부터 정보로 시작.

### M1 매거진 Q&A 아티클 (토스페이먼츠피드형)
- 제목: 검색 질문 그대로("~하나요?", "~있을까요?", "~어디서 확인하나요?", "~은 어떻게 하나요?").
- 첫 문단: "결론부터 말하면, ~예요." 2~3문장으로 답 먼저 + 타이쿤이 답의 일부로 자연스럽게 등장.
- 둘째 문단: 독자 상황 공감 2~3문장 → "~가 무엇인지, ~와 어떻게 다른지, ~하면 어떤 점이 좋은지 알아볼게요."
- 소제목(H2) 3~4개 전부 질문형. 각 소제목 아래 첫 문장이 바로 답("네. ~", "~예요.").
- 해요체(~해요, ~예요, ~죠). 단정 대신 "도움이 될 수 있어요" 등 차분한 정보 톤, 결론·CTA에서만 타이쿤을 강하게 권함.
- 비교표 또는 '주요 특징' 목록 중 하나만(업체명 없이, 수수료·요율 숫자 금지).
- 끝: "자주 묻는 질문" H2 + Q. 2개(질문 굵게, 답 1~2문장) → 마무리 H2 "우리 가게에 맞는 결제 방식을 확인해 보세요" 류 → CTA.
- 조건 안내 문장 필수: "실제 조건은 서비스 정책에 따라 달라질 수 있어요" + 기존 이탤릭 마지막 줄.
- M1 카테고리(돌아가며): 결제 A-Z(개념) / 가게 시작할 때(창업 체크리스트) / 가게 운영할 때(운영 팁) / 결제가 필요할 때(결제 링크·QR·결제 페이지) / 정산·자금 관리 / 업종별 활용 / 세금·서류 기초(바뀌지 않는 일반 개념만, 세율·기한·법 조항 숫자 금지).

### M2 카드뉴스 시리즈 (나이스 인스타형)
- 본문 = 도입 1~2문장 + 카드 7장 이미지(순서대로) + 각 카드 아래 한 줄 설명(없어도 됨) + CTA. 카드 이미지가 본문의 중심.
- 카드 파일: _thumb/extra/<슬러그>-c1.md ~ -c7.md, thumb_style "s19"(+ 색 변형 " c2"/" c3"/" c4" 중 하나를 글 전체에 통일), thumb_size "sq", thumb_badge(시리즈명), thumb_title1(짧은 머리말, 예: "STEP 1", "Q.", "이럴 때"), thumb_title2(핵심 문장 14자 이내), thumb_sub(본문 2~3줄, 줄바꿈은 <br>, 한 줄 18자 이내), thumb_lbl("01 / 07"), thumb_icon(이모지 1개, 카드마다 다르게).
- 카드 구성: 1 표지(시리즈명 + 제목) → 2 이런 고민 → 3~5 STEP/핵심 3가지 → 6 정리/비교 → 7 CTA("가입 후 인증만 하면 바로 시작 · tycoonkr.com").
- 시리즈(돌아가며, 제목 앞에 붙이기):
  · [업종별 활용 TIP] ○○ 사장님의 카드결제 (업종 확대 목록 순서대로)
  · [처음이어도 쉽게] 결제 링크로 카드결제 받는 흐름 / QR 결제 흐름 / 당일·익일 정산 고르는 법 (실제 화면 캡처 없이 흐름 설명만, 메뉴명·버튼명 지어내지 말 것)
  · [결제 개념 사전] PG란? / 정산 주기란? / 결제 링크 vs QR vs 결제 페이지 / 당일 vs 익일 정산 — 마지막 카드에 "다음 편: ~" 예고
- M2는 미디엄·Substack 제외(블로거·깃허브·워드프레스에서만).
