# 타이쿤 콘텐츠 플레이북 (매일 자동 발행용)

매 발행마다 아래 4가지를 조합합니다: [주제] × [형식] × [제목 패턴] × [이미지 스타일].
같은 채널의 최근 글 5개와 주제·형식·스타일이 겹치지 않게, 같은 날 다른 채널과도 겹치지 않게 고릅니다.
도입 훅·CTA 문구도 아래 목록에서 매번 다른 것을 골라 변형해서 씁니다(그대로 복붙 금지).

## 1. 형식 (20종)
F01 단계별 가이드(1~5단계)
F02 FAQ(질문 7~10개)
F03 체크리스트(□ 항목 7~10개)
F04 가상 상황 시나리오("예를 들어 ○○ 사장님이라면")
F05 용어 풀이(5~8개 용어)
F06 오해와 진실(O/X 5개)
F07 비교 분석(표 중심, 업체명 없이 일반 PG·단말기·계좌이체와 비교)
F08 업종별 플레이북(업종 4~5개별 활용법)
F09 하루 타임라인("오전 10시 결제 → 오전 11시 입금" 식 가상의 하루)
F10 숫자로 보는 정리(사실 수치만: 1시간, 오후 4시, 3가지 결제 방식 등)
F11 실수 TOP 5(카드결제·정산 관련 흔한 실수와 해결)
F12 Before / After(계좌이체만 받던 때 vs 타이쿤 쓴 후, 가상 예시)
F13 질문 하나 깊게 파기("왜 카드 매출은 늦게 들어올까?" 하나를 깊이)
F14 초보자 입문 가이드(처음 카드결제 받는 사람용 A to Z)
F15 상황별 Q&A 카드(짧은 질문 10개 + 한두 줄 답)
F16 시즌·이벤트 활용(명절, 연말, 블랙프라이데이, 개학, 휴가철 등 시기별 활용)
F17 대화체 인터뷰(가상 인물과의 Q&A — 가상임을 명시, 실존 인물·후기처럼 쓰지 말 것)
F18 한 장 요약(핵심 5줄 요약 + 짧은 설명)
F19 따라 하기 미션(오늘 바로 해볼 3가지 행동)
F20 독자 고민 상담("이런 고민 있으신가요?" 3~4개 고민과 해결)
※ 미디엄·텀블러는 표 미지원 → F07은 블로거·깃허브에서만.

## 2. 주제 뱅크 (대상별)
### 소상공인·자영업
- 카페·디저트 매장 예약금/단체 주문 카드결제
- 미용실·네일샵 예약금 노쇼 줄이기(선결제 링크)
- 꽃집·케이크 주문 제작 선결제
- 푸드트럭·야시장 QR 결제
- 학원·공부방 수강료 카드결제
- 필라테스·PT 회원권 결제 링크
- 반찬가게·도시락 단체 주문
- 사진관·스튜디오 촬영비
- 인테리어·수리 현장 결제
- 이사·청소 서비스 현장 카드결제
- 정산 빠르면 재고 회전이 빨라지는 이유
- 월말 자금 압박 줄이는 법
- 카드 안 되는 가게가 놓치는 손님
- 단말기 없이 시작하는 카드결제
- 매장 밖(배달·포장·방문)에서 결제받기
### 프리랜서·1인 사업자
- 디자이너 착수금·잔금 받기
- 영상 편집자 작업비
- 번역·통역 의뢰비
- 과외·레슨비 회차 결제
- 웨딩·행사 사회자/촬영 출장비
- 컨설팅·코칭 세션비
- 미수금 줄이는 결제 습관
- 견적서 보내고 바로 결제받는 흐름
- 국내 고객 카드결제로 일 더 받기
- 1인 사업자 현금흐름 관리
### 유튜버·크리에이터·스트리머
- 방송 중 QR 후원 받기
- 팬미팅·오프라인 이벤트 참가비
- 굿즈 선주문 카드결제
- 온라인 클래스·전자책 판매
- 협찬·광고 대금 빠르게 받기
- 외주비 지급 위해 빠른 정산이 필요한 이유
- 장비 투자 타이밍과 정산 속도
- 후원 창구를 하나 더 만드는 법
- 커뮤니티(디스코드·오픈채팅) 멤버십 결제
- 크리에이터 수익 구조와 현금흐름
### 라이브커머스·온라인 셀러
- 라이브 방송 중 결제 링크 고정
- 인스타 DM 주문 카드결제
- 공동구매 결제 받기
- 중고·리셀 거래 결제
- 핸드메이드 작품 판매
- 재고 회전 빠르게 하는 정산 전략
- 방송 전 준비 체크리스트
- 결제 이탈 줄이는 법
- 밴드·카페 판매 결제
- 플리마켓·팝업스토어 카드결제
### 파트너(총판·지사) 모집
- 퇴근 후 부업으로 결제 영업
- 보험·카드·통신 영업 경력자의 전환
- 자영업자 인맥 많은 사람의 부업
- 크리에이터 매니저·MCN 출신의 기회
- 재고·초기비용 없는 부업 조건
- 소개만 해도 되는 영업의 장점
- 파트너가 고객에게 설명하는 30초 스크립트
- 파트너 적합도 자가진단
- 부업 시간 관리법
- "정산 빠른 PG"가 영업하기 쉬운 이유
### 공통 정보
- PG란 무엇인가
- 카드 매출 정산 구조 쉽게 이해하기
- 당일 정산 vs 익일 정산 언제 무엇을
- 결제 링크 vs QR vs 결제 페이지 차이
- 카드결제 시작 전 준비물
- 현금흐름이 사업에 중요한 이유
- 계좌이체만 받을 때의 리스크
- 연말·명절 성수기 결제 대비

## 3. 제목 패턴 (12종, 매번 다르게)
- "~하는 법 N단계" / "~, 아직도 ~하세요?" / "~ 체크리스트 N" / "~ 전에 꼭 알아야 할 N가지"
- "~ 사장님이라면 지금 바꾸세요" / "~ vs ~, 차이는 정산 속도" / "~ 실수 TOP 5" / "~ 완벽 정리 (초보자용)"
- "오늘 결제, 오늘 입금: ~" / "~ Q&A 10문 10답" / "~할 때 손해 보는 이유" / "~ 한 장 요약"

## 4. 도입 훅 (변형해서 사용)
독자에게 질문 / 흔한 장면 묘사 / 숫자로 시작("신청 후 1시간.") / 오해 깨기 / 하루 일과 / 짧은 대화 / 손해 느낌(구체 금액 단정 금지) / 고민 공감

## 5. CTA 변형 (매번 다르게)
타이쿤 가입하고 오늘부터 당일 정산 받기 / 지금 결제 링크 만들어 보기 / 인증만 하면 바로 시작, 타이쿤 바로가기 / 다음 결제부터 오늘 정산으로 / 내 매출, 오늘 받는 방법 확인하기 / 타이쿤에서 QR 결제 시작하기 / (파트너) 지금 파트너 문의하기 · 부업 시작 문의 · 파트너 조건 확인하기

## 6. 이미지 스타일 (thumb_style, 14종)
s1 파란 휴대폰(thumb_lbl, thumb_amount) / s2 주황 영수증(thumb_chip=결제 방식, thumb_amount) / s3 초록 채팅(thumb_toast) / s4 보라 달력(thumb_lbl=달력 제목) / s5 남색 실제 QR(tycoonkr.com 연결) / s6 금색 그래프(파트너용, thumb_lbl, thumb_amount) / s7 하늘색 비교 카드 / s8 분홍 큰 숫자 "1시간" / s9 노란 체크리스트 메모 / s10 검정 라이브 방송 채팅(thumb_toast) / s11 청록 지도 핀(출장·현장 결제) / s12 연두 코인(+thumb_amount원) / s13 남보라 결제 페이지 화면(thumb_amount) / s14 검정·노랑 굵은 타이포
- 주제와 어울리는 스타일 우선: 라이브→s10, 출장·방문→s11, 프리랜서 대금→s2/s13, QR→s5, 비교→s7, 체크리스트→s9, 파트너→s6/s12/s14
- 같은 날 채널끼리 스타일 중복 금지, 같은 채널 최근 3개와 중복 금지.
- 문구(배지·제목 2줄·부제·금액·라벨)는 매번 새로. 금액은 예시용 둥근 숫자로 다양하게.
